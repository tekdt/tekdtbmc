Notes:  

1.    This is a hot fix release targeted to resolve the defects in the ‘Resolved Issues in 12.8.20.1002 Production Version release section.

2.    The RST driver and user interface version is 12.8.20.1002

3.    Known Issue is defined as a potential RST issue that has been replicated internally by the Rapid Storage Technology team but has not been root caused to be an RST defect.

4.    For customers shipping with SSHD PUIS hybrid hinting enabled and Smart Connect Technology they must use iSCT agent 4.1.2308 or 4.2.2309 or later.

5.    With SSHD +Smart connect Agent there are cases where the driver may be busy when the agent request the timer be extended which might result in a disk spinup. To work around this scenario and get the iSCT and SSHD functionality, it is advisable to set AoacTimeout to 60 sec where the current default value is 10 sec.

·         Registry details: [HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\services\iaStorA\Parameters\Device] “AoacTimeout” "=dword (0x3c (h) or 60 (d)).

6.    Depending on the SSHD vendor, customers utilizing SSHD + Smart Connect Agent may encounter more than expected SSHD spin-ups.  Good spin suppression has been measured on at least one vendor’s SSHD when AOAC Timeout is set to 60 seconds.  RST and Smart Connect Agent teams working with SSHD vendors on root causing the issue.
